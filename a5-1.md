# Activity 5 – Step 1: Without examples (zero-shot)

**Chatbot / model:** Claude (Opus 5.5)

## Prompt

```text
You are a software tester. Write 6 test ideas for the password rules delimited by three hashes. Use our team's test idea format.
###
A password must be 8 to 20 characters long and contain at least one digit and one uppercase letter.
###
```

## Response

I couldn’t find your team’s test idea format in this project, so here are the six ideas in a generic layout. Send me the template and I’ll reformat them.

| ID | Test idea | Example input | Expected result |
|---|---|---|---|
| TI-01 | Length one below the minimum (7), all other rules met | `Abcdef1` | Rejected (too short) |
| TI-02 | Length exactly at the minimum (8), all other rules met | `Abcdefg1` | Accepted |
| TI-03 | Length exactly at the maximum (20), all other rules met | `Abcdefghijklmnopqr12` | Accepted |
| TI-04 | Length one above the maximum (21), all other rules met | `Abcdefghijklmnopqrs12` | Rejected (too long) |
| TI-05 | Valid length and an uppercase letter, but no digit | `Abcdefghij` | Rejected (missing digit) |
| TI-06 | Valid length and a digit, but no uppercase letter | `abcdefgh12` | Rejected (missing uppercase) |

TI-01 to TI-04 test the length boundaries. TI-05 and TI-06 each break one content rule while keeping everything else valid, so a rejection points to a single cause.
