# Activity 2 – Step 1: Try the delimiter prompt

**Chatbot / model:** Claude (Opus 5.5)

## Prompt

```text
You are a SQL data generator. Generate five rows of SQL for a MySQL database.
* The table name is identified with a # sign.
* Each table column is identified with a % sign
* Each column is described in order of name, data type and data options using the | sign
* If a column data option says random, randomize data based on the suggested format and column name
Here are the instructions:
# rooms
% room_name | string | random
% type | string | 'single' or 'double'
% beds | integer | 1 to 6
% accessible | boolean | true or false
% image | string | random url
% description | string | random max 20 characters
% features | array[string] | 'Wifi', 'TV' or 'Safe'
% roomPrice | integer | 100 to 200
```

## Response

Since MySQL has no native array type, features is stored as a JSON array. The CREATE TABLE is included so the script runs on its own.
```sql
-- ============================================================
-- Table: rooms
-- Notes:
--   * MySQL has no native ARRAY type, so `features` is stored as
--     a JSON array (e.g. ["Wifi","TV"]).
--   * BOOLEAN in MySQL is an alias for TINYINT(1); TRUE = 1, FALSE = 0.
--   * CHECK constraints enforce the data options from the spec
--     (MySQL 8.0.16+ enforces CHECKs; older versions ignore them).
-- ============================================================
CREATE TABLE IF NOT EXISTS rooms (
    id           INT AUTO_INCREMENT PRIMARY KEY,           -- surrogate key
    room_name    VARCHAR(100)  NOT NULL,                   -- random room name
    type         VARCHAR(10)   NOT NULL,                   -- 'single' or 'double'
    beds         INT           NOT NULL,                   -- 1 to 6
    accessible   BOOLEAN       NOT NULL DEFAULT FALSE,     -- true / false
    image        VARCHAR(255)  NOT NULL,                   -- random image URL
    description  VARCHAR(20)   NOT NULL,                   -- max 20 characters
    features     JSON          NOT NULL,                   -- subset of 'Wifi','TV','Safe'
    roomPrice    INT           NOT NULL,                   -- 100 to 200

    CONSTRAINT chk_rooms_type  CHECK (type IN ('single', 'double')),
    CONSTRAINT chk_rooms_beds  CHECK (beds BETWEEN 1 AND 6),
    CONSTRAINT chk_rooms_price CHECK (roomPrice BETWEEN 100 AND 200)
);

-- Sample data: 5 rows
-- Each description is 20 characters or fewer.
-- ============================================================
```
